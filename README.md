# Omarchy themes and actions widget

This folder contains the custom Omarchy themes, their backgrounds, and the
Widget Island actions-panel plugin.

## Install a theme

Copy a theme directory into `~/.config/omarchy/themes/`, then apply it:

```bash
omarchy theme set ember-nocturne
```

Cycle its backgrounds with:

```bash
omarchy theme bg next
```

## Install the actions widget

From the `widget-island/` directory, run:

```bash
./install.sh
```

Then add the shortcut shown by the installer to
`~/.config/hypr/bindings.lua`, reload Hyprland, and press **Super + Shift + I**.

## Included themes

- `ember-nocturne`
- `cybertruck-sunrise`
- `cybertruck1`
- `superheavy-launch`
